# \# vpc-chat-app

# 

# A Discord-like web chat app running inside a private AWS VPC,

# reachable only through a WireGuard VPN.

# 

# \## Goals

# \- Real-time chat (channels, message history)

# \- Containerized with Docker, deployed on AWS (VPC, EC2, RDS, S3)

# \- Infrastructure as code with Terraform

# 

# \## Tech stack

# Python (FastAPI), PostgreSQL, Redis, Nginx, Docker, AWS, WireGuard, Terraform

# 

# \## Status

# Work in progress. See docs/roadmap.md for the plan.
